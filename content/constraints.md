# KiddoKlub Constraints — the never-do list

**Canonical source of truth for all banned characters, phrases, and moves.**
Loads on every outbound draft. Cheapest in tokens, highest in impact.
`kiddoklub-voice-audit` reads THIS file to gate. Do not duplicate this list elsewhere; point here.

Per Van Clief Constraint 05 (voice architecture): this is File 3 of 3. It changes often — add a line whenever a new pattern annoys you.

## Banned characters (auto-reject)
- Em dash `—`
- En dash `–`
- Spaced hyphen used as a dash ` - `
Use periods, commas, semicolons, or parentheses instead.

## Banned phrases (AI tells — instant reject)
- "elevate" / "transform" / "unleash" / "next-level" / "level up"
- "game-changer" / "unlock" / "premium experience" / "world-class"
- "we're excited to" / "delighted to" / "thrilled to"
- "let me tell you" / "here's the thing"
- "in today's fast-paced world"
- "delve" / "tapestry" / "navigate the landscape"
- "boost your" / "supercharge"
- "embark" / "crafting" / "realm" / "skyrocket" / "in a world where" / "revolutionize" / "disruptive" / "utilize" / "dive deep" / "illuminate" / "unveil" / "pivotal" / "intricate" / "elucidate" / "harness" / "groundbreaking" / "cutting-edge" / "remarkable" / "glimpse into" / "testament" / "moreover" / "furthermore" / "ever-evolving" / "seamless"
- Any line that starts with `🎉` or three emojis

(NOT banned: casual filler like "just", "really", "very" — these read as natural in Nadine's warm voice. Only AI-tell vocabulary is barred.)

## Banned moves
- **First touch:** never lead with "I run KiddoKlub" / "we offer" / "we provide" / "our service". Never put a price, link, or brand name in the opener. First message is 100% relationship, 0% pitch.
- **Sign-off:** never `— Nadine` (em dash). Never "Best regards" / "Sincerely" / any Western corporate close.
- **Emoji:** never stack. One per line max. Sign-offs use heart-cream 🤍 or heart-bone only.

## Hard prohibitions (KiddoKlub-specific)
- Never auto-translate Arabic. EN + AR written in parallel by a native speaker. Use حفلة (informal "party"), never حفل (formal "event").
- Never publish the Klub Signature exact base price. Frame as "starting from QAR 3,800 — let's chat."
- Never claim "stocked in UAE" / "Dubai stock" / "fast UAE delivery" / short UAE lead times. No UAE inventory exists.
- Never mention Equipt, Pulse, Mohammed, AbdulSalam, or ivan@equipt.shop. KiddoKlub trades under Nadine's name only.
- Never sign as Ivan. Customer trust = Nadine.
