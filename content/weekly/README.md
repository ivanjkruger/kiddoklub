## Coordination with Session B

This folder is **repo-side briefs**: hooks, Seedance prompts, CapCut shot lists, posting times, voice-audit verdicts.

When the briefs reference "AR caption written by native speaker," that's Session B's deliverable in the caption bank, not a job for the content-engine skill.

## Voice-audit gate

Every reel and carousel here has been pre-audited against `kiddoklub-voice-audit` rules:
- No em/en dashes
- No AI tells (elevate / transform / unleash / etc.)
- BLUF + short paragraphs
- Photo-permission opt-out language on any post involving customer faces
- AR written in parallel, never auto-translated
- No Equipt entanglement
- Klub Signature exact base price never published
